# Copy source-list entries for several Sources

**Status:** idea, not scheduled (user, 2026-11-13).

## Problem

A bibliography (the source list at the end of a report or family history) has one entry per Source. Spike 15 gives each Source page **Copy source-list entry** ([`evidence-explained-citation-map.md`](../deployment-plan/spike-15/evidence-explained-citation-map.md) § 6.10), so building a list of twenty Sources means visiting twenty pages.

## Rough shape

- Select several Sources in the Sources list and copy their source-list entries together, one per line, in the order a source list uses (by the entry's text, which starts with what it is filed under).
- Perhaps: from a Person page's Sources section, copy the list for every Source cited on that person.
- Rich text, italics kept, as the single-Source copy does.

## Open questions

- Sort by the rendered entry, or by the Sources list's current sort?
- Grouping headings (by type, by jurisdiction), as some source lists do?
- What a Source whose type has no list format contributes: its title, or nothing?
