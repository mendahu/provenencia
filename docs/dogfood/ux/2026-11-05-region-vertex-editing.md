# Region vertex editing: add by edge, keyboard nudge, VoiceOver

- **Date:** 2026-11-05
- **Type:** Idea
- **Where:** Citation composer / artifact region overlay
- **Annoyance:** A saved region can be reshaped by dragging a vertex, moved by its outline and shortened by right-clicking a vertex, but there is no way to add a vertex to a saved region, nudge a vertex with the keyboard, or reach a vertex with VoiceOver.
- **Wanted:** Clicking an edge adds a vertex there; arrow keys nudge the grabbed vertex; each vertex is its own VoiceOver element.
