# Dogfood notes

Friction found while using Provenencia on **real research**, not a planned feature spike. These notes come from people using the app. PR follow-ups, review findings and plan Out lines never go here; ask the user where they go.

[`ideas/`](../ideas/) is for unscheduled product shapes. [`deployment-plan/`](../deployment-plan/) is for committed implementation slices. This folder is the in-between: “this was annoying while I was entering data.” Adding a note does not schedule it.

## Log

| Doc | Use |
| --- | --- |
| [**UX entries**](ux/) | One file per finding (`ux/YYYY-MM-DD-<slug>.md`). Add here first. |

When a note is big enough to park longer-term, or when you decide to fix a cluster, move it to `ideas/` or into a spike and delete it here.
