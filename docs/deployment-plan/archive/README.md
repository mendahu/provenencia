# Closed spikes

Each folder is a **decision note**, not a changelog. PR order, checklists, and Claude Design briefs live in git.

Live behavior that outgrew a spike stays next to it when it is still the contract (Spike 3: [`navigation-history.md`](spike-3/navigation-history.md), [`omnibar-search.md`](spike-3/omnibar-search.md)). Domain rules stay in [`docs/`](../../).
