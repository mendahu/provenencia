## S16-40 — An event records As of dates, and matching reads them as bounds

**Landed 2026-11-16** in [#869](https://github.com/Jake-Robins-Studios/provenencia/pull/869). A new catalog seeds As of (`as_of`, date, multiple, locked on `event`, after End date), so an attestation such as an obituary's "of Town Y" is no longer recorded as when an event happened; the `date` and `end_date` descriptions point to it. Existing catalogs gain no `as_of`; nothing reads an event's as-ofs for display until S16-42. Minor version bump to 0.18.0.
