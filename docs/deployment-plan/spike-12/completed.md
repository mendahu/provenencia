# Spike 12 — Completed

One short paragraph per landed PR, newest first. Written by the PR that lands it.

## S12-23 — The app opens only safe files and links

**Landed 2026-10-28** in [#608](https://github.com/mendahu/provenencia/pull/608). A project folder someone shares can no longer make Provenencia launch a program. `mediatypes` holds one table of stored types and their extensions, and `objectpath.Rel` returns a path only for a type on it, so a `files` row damaged to another type is listed with an empty path instead of failing the page, and the Source page and canvas Open say "Provenencia won't open “name”…". Open refuses a name with no extension or a type that could run a program or open another item (`IngestMediaPolicy.isExecutableType`, now shared with ingest and covering stored links and Terminal files) and opens everything else with the app for its file type, never one a setting stored on the file names; the execute bit alone refuses nothing, because exFAT and FAT volumes report it on every file. A saved metadata link opens only through `open_href`, computed in Go for url fields from `urlshape.OpenHref`, so `file:` and `smb:` values show as plain text. The canvas callout's title is now "Can't open the file". Nothing else changes for researchers.

## S12-38 — Add an Artifact without a graph; the card saves links in one write

**Landed 2026-10-28** in [#605](https://github.com/mendahu/provenencia/pull/605). A card's Save is one `updateArtifact` with the label, description and every link, so a refusal leaves nothing half applied; every box the engine's preflight reports is locked, and a refused save names the graph and says the changes are kept. The graph form locks every Artifact the engine says it must keep, re-reads its locks after any refused edit, and a new graph starts with the Artifacts in no graph checked. `LinkEvidenceGraphArtifact` and `UnlinkEvidenceGraphArtifact` are gone on both sides.

The card's link locks come from one preflight call; no view changes otherwise, and S12-38 builds the chrome.
